# AG Grid + Taiga UI multiple onboarding prototype (ngx-ui-tour)

Учебный прототип нескольких последовательных онбордингов на Angular, Taiga UI, AG Grid и `ngx-ui-tour-tui-hint`.

## Лицензия и независимость

Это независимый open-source проект [splincode-taiga-labs](https://github.com/splincode-taiga-labs),
неофициальный и не аффилированный с Taiga UI или Pineopticone.

Оригинальный код репозитория распространяется по [лицензии MIT](LICENSE).
Сторонние библиотеки, ресурсы и товарные знаки сохраняют собственные лицензии и правообладателей.
Taiga UI используется как внешняя зависимость, а не как часть этого проекта.
